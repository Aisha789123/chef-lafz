Make PNG app icons

Open this page with Live Server (so it can read ../icons/*.svg), then press the button. Three PNG files download. Put them in the icons/ folder, then add these lines to the "icons" list in manifest.json:

{ "src": "icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
{ "src": "icons/icon-512.png", "sizes": "512x512", "type": "image/png" },
{ "src": "icons/maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
