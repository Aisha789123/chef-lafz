# images/

Put your own photos or pictures here, one folder per section, for example:

- `images/spices/cumin.jpg`
- `images/tools/ladle.png`

Then change the word's `"image"` in the JSON file to that path (see the main README → "Change a picture").
Square pictures look best. Keep each file small (under 100 KB) so the app stays fast on a slow connection.
